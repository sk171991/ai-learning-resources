## Study workflow

1. Pick one topic and read one foundational resource.
2. Summarize the main ideas in your own notes.
3. Build a small example that applies the concepts.
4. Record design decisions, limitations, and evaluation results.
5. Revisit the relevant cheat sheets and interview questions to test retention.

> These files are learning references. Validate technical guidance against current official documentation before using it in production.
